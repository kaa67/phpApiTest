# Kaa php framework

## Структура уроков

1. Автозагрузка. psr-4
2. Инверсия зависимостей. Использование контейнера зависимостей. psr-11
3. Composer и использование сторонних библиотек.
4. Request и Response. psr-7
5. Pipeline и Middleware. psr-15
6. Routing и обработка запроса.
7. Обработка исключений.

## Файлы фреймворка

1. index.php - точка входа в приложение
2. library.php - библиотека полезныx функций
3. App.php - основной класс фреймворка
4. ExceptionHandler - обработчик исключений
5. ApiController - абстрактный класс родительского контроллера
6. CORSMiddleware - промежуточное ПО для обработки CORS
